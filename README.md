# KoneKERP BPM Sarastya

Enterprise Resource Planning with Business Process Management System

## Project Structure

```
konekerp-bpm-sarastya/
├── backend/              # .NET Core Web API
├── frontend-web/         # React + Vite Web Application
├── frontend-mobile/      # Flutter Mobile Application
├── deployment/           # Deployment configurations
└── docs/                # Documentation and diagrams
```

## Tech Stack

### Backend
- .NET 8.0
- Entity Framework Core
- PostgreSQL/SQL Server
- JWT Authentication
- Serilog

### Frontend Web
- React 18
- TypeScript
- Vite
- TailwindCSS
- Shadcn/ui
- Zustand

### Frontend Mobile
- Flutter
- Dart
- Provider/Riverpod
